## 测试条件

使用当前 `rm65-servo:humble`、默认模型和控制参数，通过真实manual HTTP入口发送方向/使能；InputAdapter → PoseTracking/Servo → JTC → MuJoCo保持原链路。没有修改运动参数、保护阈值、初始关节配置或发送方式。全部容器使用 `--network none`，未连接PICO、远程板或真实机器人。

正式重复为 `run3/run4/run5`：三次独立启动，每次约132.5秒，共采集99,396个实际关节样本。包含±X/Y/Z、±RX/RY/RZ、平移/旋转混合、松开、断心跳及10秒静止。平移目标速率20mm/s、每方向0.6秒；旋转0.12rad/s、每方向0.5秒。方向归零后**继续保持使能6秒**测收敛，随后才释放；每次新段先保持零方向0.2秒建立锚点。

实际TCP由原 `/joint_states` 的q和同模型只读FK计算，初始位置/姿态均与常规TF交叉核对。目标与反馈按ROS源时间因果零阶对齐，不使用未来目标；三次正式重复的目标同步覆盖均100%。同时记录原目标、限幅后目标、Servo轨迹、JTC参考/实际/误差及状态。`analysis/summary.json`保存配置、控制器、模型、测量工具版本与逐段指标。

以下范围取三次正式重复。门槛是本轮预先固定的工程筛查线，不是厂家指标或插接任务标准。P95指95%的有效移动采样不超过该误差；各轮分别计算分位数后列范围。

每轮16个固定目标保持段中，仅2段在6秒内进入“位置≤1mm且姿态≤0.5°”并连续保持0.5秒。X正向的10%闭环响应延迟约2.24–2.69秒：它包含整个闭环响应，不能称为通信延迟。X保持末秒还移动约0.76–0.79mm，RX保持末秒还转动约0.22–0.23°，所以这些保持段仍在缓慢收敛。

三次重复中，同名保持段相对起点的位移三分量标准差最大0.350mm，旋转三分量标准差最大0.104°；该重复性描述含当前输入积分与模型，不能消除共同跟踪偏差。三轮无NaN、关节越限、反馈时间回退或超过200ms的反馈缺口；实测关节速度最高为配置限速约31%。JTC参考与实测关节误差在有效跟踪段的P95约0.0085–0.0087°，关节反馈源周期P95约4.02–4.03ms。

停止时间从测量阶段起点算起，速度须连续200ms低于1mm/s、1°/s及各关节1°/s。断心跳阶段起点与最后一帧已发送心跳相差不足50ms；这些结果是本次本机测量值，不是网络或实体停止的最坏保证。

## 分层诊断

- 同模型离线几何Jacobian初始条件数约20.00，X保持末约20.93，当前姿态已位于Servo的17–30奇异减速区。运动/保持中确实观察到减速状态；这些数据不足以将全部滞后归因于奇异减速。
- 当前平移P=1.5、角度P=0.5，I/D为零，会产生闭环动态滞后。JTC参考与实际关节之间的误差较小，但短时参考反复更新、平滑、各关节执行响应及耦合对末端速度的影响尚需隔离；不凭小关节误差直接宣布物理执行理想。
- 两轴GenericSystem对照使用相同控制配置，RX保持末秒仍有约1.44°误差；开启MuJoCo画面的两轴对照约1.64°。两种对照均复现慢收敛。三次正式重复及有画面对照的物理时间倍率约1倍，未把clock消息条数当物理推进速度。
- 只读检查的13个离散姿态无几何接触；该检查没有覆盖整段动态接触，也没有辨识实际执行器参数。

下一阶段先定位并改善**共享运动层**的方向响应和收敛，保持现有保护，再用同协议、同筛查线复测。通过后仍需帧/工具/场景建模、实际UDP、停止及固件等现场准入证据，才进入受控真机测试。
