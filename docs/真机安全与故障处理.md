# 真机接入与故障处理

2026-10-28 已在 ARM64 板端部署完整 **PICO + hardware-dry-run 真机只读链**，原生SDK、输入适配、Servo/JTC和官方驱动共同运行，收到持续更新的真实反馈。运动权限关闭，真实头显、实体跟随和停止尚未验收。流程统一使用 MoveIt Servo / JTC，不再启动旧 Python 控制器。

## 1 先做只读验证

当前已有 `/home/rm/EthanTao` 的PICO只读会话，查看时直接运行 `ssh rm '/home/rm/EthanTao/environment.sh status'`，输入检查使用 `environment.sh input`；不必再次启动或构建。环境自检、头显地址及板子重启后的明确只读启动见[远程板环境](远程板环境.md)。下文PICO命令只用于说明启动器，当前运行会话无需重复启动。

恢复板子供电和联网后，先确认架构、Docker、SDK、固件、唯一 UDP 接收者及现场急停。环境工具只查询，不启动节点或连接控制器：

```powershell
python scripts/tools/inspect_moveit_environment.py --ssh-host rm --sudo-docker --output build/validation/moveit_environment_after_power_on.json
```

确认后，下面命令会**启动官方 SDK 并连接真实控制器读取状态**，但不创建运动/停止执行接口。示例地址必须换成机械臂能访问的 Linux 板地址：

```powershell
python teleop.py --mode hardware-dry-run --input pico --udp-ip 192.168.10.20 --print-command
python teleop.py --mode hardware-dry-run --input pico --udp-ip 192.168.10.20
```

Dry Run 不等于零设备交互：驱动会配置 UDP 状态推送、读取 SDK 状态；新原生权限为 false 时不发运动与停止。旧厂商运动 topic 被关闭。严禁另启旧控制程序/另一 SDK 发送者。

## 2 真机执行的前置证据

复制 [hardware_validation.example.yaml](../ros2_ws/src/rm65_servo_teleop/config/hardware_validation.example.yaml) 为同目录现场文件。默认 false 不得凭启动成功改为 true；至少要有：

- 控制器/固件/SDK 兼容证据；
- 多姿态下侧装 base、TCP、工具及官方 FK/UDP 一致性；当前历史 d6/TCP 候选不能直接批准执行；
- 同包真实 q/qdot/错误、时钟/包编号、速度单位及丢包行为；
- 全部运动部件与场景的碰撞建模，包含手、相机支架、工件/障碍；
- 停止接口、SDK 返回、静止反馈和故障恢复的现场证据；
- 匹配模型、SRDF、控制配置、驱动提交、补丁和控制器地址的部署哈希。

历史 5 mm / 2°只能排除明显帧不一致，不是插接任务精度认证。哈希可通过 `--model-only` 打印；该参数不启动 ROS 节点，但默认启动器仍会同步并构建镜像。改动配置/补丁后旧现场文件失效。

执行模式另需 `--live-ack "RM65 LIVE VALIDATION"`，现场文件和 Linux 启动时双重核对；当前没有可用于真实执行的有效文件。现有只读会话已连接控制器，但没有进行真实发送或实体运动验收。

<a id="rearm"></a>
## 3 保持、停止与恢复

启动先释放 Grip。新段以新鲜实测 TCP 锚定；输入、TF 或反馈过期会关闭跟随，不能用重打时间戳的缓存继续执行。

正常松 Grip 取消位姿跟随，设备端走已确认停止流程。故障硬停并锁存；SDK 停止成功与实体静止分别记录。停止未确认时不重使能。恢复须经过故障后释放 Grip、真实反馈新鲜且无错误、六轴低于静止阈值，并完成原生代次握手。

Python 桥只保留最新有效指令；原生端再次检查时效、代次和反馈，串行 SDK 发送/停止。桥停止或失联、UDP 超时也由原生 watchdog 处理。驱动退出会尝试关闭流并停止；它不能代替现场急停或物理停止验证。

<a id="home"></a>
## 4 当前不提供自动回位

启动、B 键、松 Grip 和故障均不发 Home。配置中的 home 仅用于模拟初始关节值，不是上电回位指令。未来若需要回位，须接入同一命令仲裁，验收整条路径、取消与停止。

<a id="validation"></a>
## 5 现场运动验收与采集

只读通过后再制定有监护、净空、急停的低速小范围测试：逐轴方向、Grip、掉线/反馈失效、停止、重新使能、跟踪误差、速度与长时延迟分位数分别保存证据。当前配置名义 TCP 速度 0.05 m/s、0.25 rad/s，关节速度为型号上限的 10%；尚无硬加速度/jerk 限制或物理速度保证。

模型碰撞开启不等于真实环境已建模；Servo 拒绝原因先查记录，不能为“不动”直接关保护。无独立力传感器，不能把 ROH 电流当作实际接触力。

控制链通过后仍需图像/深度、手状态、同步、标定、Episode 完整性与任务成功率验证，才能用于高质量采集。详见[实验记录](真机实验记录.md)。
