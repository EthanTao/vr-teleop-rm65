# 仿真操作手册

> **写给谁**：第一次上手这套系统的操作者。不需要懂代码或机器人学，按步骤做就能跑起来。
> **是什么**：用 PICO 头显 + VR 手柄控制 RM65 六轴机械臂的仿真环境。捏住手柄 Grip 移动，Meshcat 里的机械臂跟着动。
> 真机操作是另一套流程，安全前置条件见 [真机安全与故障处理.md](真机安全与故障处理.md)。

---

## 1. 前置条件

| 物品 | 说明 |
|------|------|
| PICO 4 Ultra 头显 + 手柄 | 戴头上，手拿手柄 |
| 一台电脑（Windows / Mac） | 只当"遥控器"：连远程服务器、开浏览器看画面 |
| 远程 Linux 板 + Docker | **仿真实际跑在这里**，不在你的电脑上 |
| 局域网 | 头显与远程板在同一网段 |
| SSH 客户端 | Windows 自带 OpenSSH；Mac 自带终端 |

仿真需要 Linux + 显卡 + 专用库（Placo / Meshcat），这些已在远程板上部署好，本机不跑。

---

## 2. 三窗口模型

```
你戴 PICO 头显
   │ WiFi 直连远程板 192.168.0.115:63901
   ▼
远程板 → Docker 容器 xrobo-vr-teleop
            │  仿真进程 → Meshcat :7000
            ▼
      SSH 隧道 18081→7000
            ▼
      本机浏览器 http://127.0.0.1:18081/static/
```

同时开三个窗口：

| 窗口 | 内容 | 说明 |
|------|------|------|
| ① SSH 隧道 | `ssh -N -L ...` | 后台保持，**不能关** |
| ② 仿真控制台 | 看日志 | 或由 `teleop.py` 代管 |
| ③ 浏览器 | `http://127.0.0.1:18081/static/` | 看机械臂 |

**一键替代**：`python teleop.py --mode sim --home-joint-deg J1 J2 J3 J4 J5 J6` 会自动完成同步 + 建隧道 + 启动 + 清理，可跳过第 3～4 节。

---

## 3. 第一步：建立 SSH 隧道

```bash
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=20 -o ServerAliveCountMax=3 \
  -L 18081:127.0.0.1:7000 \
  -L 63901:127.0.0.1:63901 \
  rm
```

- `rm` 是已配置好的 SSH 别名：实验室内网自动走 `192.168.0.115`，宿舍/校外自动回退 Tailscale。强制走 Tailscale 用 `ssh rm-ts`。
- 也可用仓库脚本：`scripts/tools/start_meshcat_viewer.sh`（Git Bash）或 `start_meshcat_viewer.bat`（Windows 双击）自动建隧道 + 开浏览器。
- **执行后没有任何输出才是正常的**，不要关窗口。隧道里的 `63901→63901` 仅供本机调试；头显直连远程板，不依赖它。

验证：

```bash
curl -I http://127.0.0.1:18081/static/
```

---

## 4. 第二步：启动仿真

```bash
# 登录板子并进入容器
ssh rm
sudo docker exec -it xrobo-vr-teleop /bin/bash

# 容器内启动
export XROBO_GRIP_THRESHOLD=0.2
python scripts/simulation/teleop_rm65_sim.py --home-joint-deg J1 J2 J3 J4 J5 J6
```

`J1..J6` 单位为**度**，必须是现场确认无碰撞、远离奇异点的侧装 Home Pose。官方把 `[0,0,0,0,0,0]` 列为边界奇异示意点，**不能当默认 Home**；未传该参数时程序拒绝启动。判据见 [RM65参数与坐标系.md](RM65参数与坐标系.md)。

可选后端：

```bash
# 官方连续 IK（容器需装与 RM65-B 匹配的睿尔曼 API2 SDK）
python scripts/simulation/teleop_rm65_sim.py \
  --home-joint-deg J1 J2 J3 J4 J5 J6 --ik-backend official
```

官方模式：Grip 锚点来自官方 FK，关节目标来自 `rm_algo_ik_remote`，Placo 只负责加载 URDF 并在 Meshcat 显示。它**不参与关节求解**。出现 `[OFFICIAL IK HOLD]` 表示本周期 IK 失败、关节越限、J3 进入默认 ±5° 排除区或关节步长过大，仿真保持上一帧关节角。该模式不支持 `--enable-self-collision-avoidance` 与 `--enable-velocity-limit`，关节步长改用 `--official-ik-max-joint-speed-ratio` 调整。

启动成功输出：

```
[INFO] control_mode=pose
[INFO] deadband_m=0.002, deadband_rad=0.03
[INFO] 平滑复位已启用
Open Placo/Meshcat: http://localhost:18081/static/
```

> 报 `ModuleNotFoundError` 说明代码没同步进容器，见 [§9](#9-常见问题)。

---

## 5. 第三步：连接头显

1. 戴好头显，打开 **XRoboToolkit** App
2. 填入 **IP `192.168.0.115`**（远程板 IP）、**端口 `63901`**
3. 点 **Connect**，确认 **Controller + Send** 状态为 **WORKING**

数据流：头显 → 远程板 `192.168.0.115:63901` → 容器内 RoboticsService。头显**直连远程板**，不要填你电脑的 IP。

## 6. 第四步：看画面

浏览器打开 `http://127.0.0.1:18081/static/`，应看到 3D 机械臂模型。

## 7. 操作

| 手柄操作 | 效果 |
|---------|------|
| **按住右手 Grip** | 激活控制，移动手柄机械臂跟随 |
| **松开 Grip** | 暂停控制，手柄再动不影响机械臂 |
| **移动右手柄** | 机械臂末端平移 |
| **旋转右手柄** | 机械臂末端旋转 |
| **按 B 按钮** | 平滑复位，约 3 秒回到 Home Pose |

技巧：

| 目的 | 做法 |
|------|------|
| 刚开始怕搞坏 | 先不按 Grip 随便动手柄 —— 机械臂不动是**正常的** |
| 精细调整 | Grip 轻握、小幅移动，机械臂小幅度跟随 |
| 大范围移动 | 捏紧 Grip、大幅度移动 |
| 姿势乱了 | 按一下 B 复位 |

## 8. 调参

### 8.1 两个核心手感参数

| 参数 | 类比 | 调大 | 调小 |
|------|------|------|------|
| 死区 `deadband` | 鼠标的"忽略微小移动" | 手抖被忽略，更稳 | 微动也响应，更灵敏 |
| 平滑系数 `alpha` | 鼠标加速度 | 反应快但可能抖 | 平滑但迟钝 |

### 8.2 运行时调参（推荐）

```bash
python scripts/simulation/teleop_rm65_sim.py \
  --home-joint-deg J1 J2 J3 J4 J5 J6 --enable-tuning true
```

在运行仿真的终端里按键：

| 按键 | 作用 | 每次变化 |
|------|------|---------|
| `d` / `D` | 平移死区 减 / 增 | ∓0.001 m |
| `r` / `R` | 旋转死区 减 / 增 | ∓0.005 rad |
| `a` / `A` | 平移平滑系数 减 / 增 | ∓0.05 |
| `o` / `O` | 旋转平滑系数 减 / 增 | ∓0.05 |
| `v` / `V` | 关节速度上限 减 / 增 * | ∓0.5 rad/s |
| `h` | 显示帮助与当前参数 | — |
| `q` | 退出调参模式 | — |

> \* 需先 `--enable-velocity-limit true`。
> **仅 Linux TTY 可用**：Windows 的 PowerShell/CMD 下按键盘无反应，必须在容器内 `docker exec -it`。

### 8.3 启动时直接指定

```bash
# 更抗抖（新手）：--deadband-m 0.005 --deadband-rad 0.05 --smooth-alpha-pos 0.25 --smooth-alpha-rot 0.2
# 更灵敏（老手）：--deadband-m 0.001 --deadband-rad 0.01 --smooth-alpha-pos 0.5 --smooth-alpha-rot 0.4
```

调参路径建议：先跑默认值 → 觉得抖就增大死区与平滑 → 觉得迟钝就减小 → 找到平衡点后按 `h` 记下数值，下次启动直接传参。

### 8.4 自碰撞避免（默认关）

```bash
python scripts/simulation/teleop_rm65_sim.py \
  --home-joint-deg J1 J2 J3 J4 J5 J6 \
  --enable-self-collision-avoidance true \
  --self-collision-margin 0.05   # 默认 0.03 m，越大越保守
```

开启后 IK 求解器增加不等式约束，可能轻微影响跟踪精度；动作不流畅时可关掉。官方 IK 后端不支持此开关。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| `Connection timed out` | 板子关机 / 断网 / IP 变了 | 确认板子状态；宿舍下用 `ssh rm-ts` 强制走 Tailscale |
| Windows 无 `ssh` 命令 | 未装 OpenSSH | `Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0`；或用 PuTTY 配两条 Tunnel：`18081→127.0.0.1:7000`、`63901→127.0.0.1:63901` |
| 浏览器 `18081` 空白 | 隧道没开 / 仿真没起 / 端口冲突 | 确认隧道窗口还在；查控制台报错；换端口如 `-L 18082:127.0.0.1:7000` |
| Meshcat 只有网格没有机械臂 | 多实例 / 端口不一致 | 杀光旧 `teleop_rm65_sim.py` 与 `meshcat.servers.zmqserver`，**只保留一个 7000** |
| 按了 Grip 但不动 | 头显未连 / Grip 阈值高 / 正在复位 / 隧道断 | 确认 App 状态 WORKING；`export XROBO_GRIP_THRESHOLD=0.2`；等复位完成 |
| 机械臂疯狂抖动 | 死区太小 + 手抖放大 | 多按几次大写 `D`（增死区）+ 大写 `A`（增平滑） |
| 不知道当前参数值 | — | `--enable-tuning true` 后按 `h` |
| 改了代码仿真没变化 | 容器里跑的是旧代码 | 用 `python teleop.py --mode sync-only` 重新同步 |
| 容器内 `import` 报错 | 用了 base Python (3.13)，依赖装在 xrobo (3.10) | 用 `/opt/conda/envs/xrobo/bin/python`，或确保 `conda activate xrobo` 生效 |
| 调参模式按键盘没反应 | Windows 不支持 | 在容器内 `docker exec -it` 运行，或用 CLI 参数 |

## 10. 参数速查

### 仿真 CLI 参数

> 以下为**仿真软件参数**，不是 RM65 本体额定参数。610/627 mm 是本体工作半径，不能替代关节约束、碰撞检查或真机安全边界。

| 参数 | 默认 | 作用 | 推荐范围 |
|------|------|------|----------|
| `--home-joint-deg` | **必填** | 六个关节角的 Home（度） | 现场验证无碰撞 |
| `--ik-backend` | `placo` | IK 后端（`placo` / `official`） | — |
| `--deadband-m` | 0.002 | 平移死区（m） | 0.001~0.01 |
| `--deadband-rad` | 0.03 | 旋转死区（rad） | 0.01~0.1 |
| `--smooth-alpha-pos` | 0.35 | 平移 EMA 平滑系数 | 0.1~0.6 |
| `--smooth-alpha-rot` | 0.3 | 旋转 EMA 平滑系数 | 0.1~0.6 |
| `--scale-factor` | 1.5 | 手柄→机械臂位移放大比 | 1.0~3.0 |
| `--follow-orientation` | true | 是否跟随手柄旋转 | true/false |
| `--enable-velocity-limit` | false | 是否限制关节角速度 | true/false |
| `--max-joint-velocity` | 3.0 | 关节速度上限（rad/s） | 1.0~5.0 |
| `--reset-duration-s` | 3.0 | B 键复位时长（s） | 0.5~3.0 |
| `--enable-self-collision-avoidance` | false | 自碰撞避免 | true/false |
| `--self-collision-margin` | 0.03 | 自碰撞安全间距（m） | 0.02~0.08 |
| `--enable-tuning` | false | 运行时调参 | true/false |
| `--official-ik-max-joint-speed-ratio` | — | 官方 IK 单周期关节步长上限（型号速度比例） | — |

### 环境变量

| 变量 | 默认 | 作用 |
|------|------|------|
| `XROBO_GRIP_THRESHOLD` | 0.5 | Grip 激活阈值，**仿真推荐 0.2** |
| `XROBO_DEBUG` | 空 | 设为 `1` 打印手柄数据调试信息 |
| `MESHCAT_HOST_PORT` | — | 容器内 Meshcat 端口映射 |
