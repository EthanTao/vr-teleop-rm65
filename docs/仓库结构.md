# 仓库结构

正式运行链为 `teleop.py` → `servo_launcher.py` → `ros2_ws/`。2026-10-26 已清走停用的旧控制源码、测试、模型和环境脚本；原文与逐文件校验值保存在[旧控制源码归档](archive/2026-10-26-legacy-control/README.md)。

| 路径 | 职责 |
| --- | --- |
| `启动.py` | 统一交互菜单：仿真 / 板端只读 / 受验证约束的正式执行；只编排现有 Servo 链 |
| `启动无手柄仿真.py`、`启动PICO仿真.py`、`启动真机.py` | 三个 Python 直接入口：MuJoCo + 网页控制 / 真实 PICO 输入仿真 / 板端真机（交互终端无参进入子菜单，非交互无参退出 2）；推荐终端 `python` 运行 |
| 三个同名 `.cmd`、`scripts/setup/start_simulation.ps1`、`start_real_robot.ps1` | 保留旧名称和参数的薄兼容入口；转发同一 Python 链，旧真机入口无参仍拒绝启动 |
| `teleop.py`、`servo_launcher.py` | 唯一命令行入口、源码同步与构建启动 |
| `pyproject.toml`、`.editorconfig`、`CONTRIBUTING.md` | 开发依赖、Python 检查规则、编辑约定与提交验证流程 |
| `.github/workflows/checks.yml` | Windows / Ubuntu 的 Python 离线检查；不部署、不连接硬件 |
| `ros2_ws/src/rm65_servo_teleop/` | 输入、Servo 封装、设备接入、模型、记录与 ROS 测试 |
| `ros2_ws/dependencies.repos`、`patches/`、`tools/` | 固定官方依赖、驱动补丁及构建准备 |
| `docker/` | MoveIt 镜像、Compose、容器入口与原生 XR 服务安装 |
| `tests_moveit/`、`conftest.py` | Windows / 本机入口测试、临时目录管理 |
| `scripts/setup/` | `launcher.py` 统一 Python 启动/准入逻辑、`menu.py` 交互菜单、WSL Docker 安装；`connect_pico_wsl.ps1` 专门管理 Windows 网络规则 |
| `scripts/tools/` | 环境只读检查、SSH 网络探测与历史研究文档生成器（非运行依赖） |
| `config/` | 本机历史标定快照；现行配置在 ROS 包内 |
| `docs/` | 当前操作手册、工作日志与历史归档 |
| `docs/data/` | 只读扫描数据（奇异自由 TCP 采样）及说明 |

本机生成物统一写入 Git 忽略的 `build/`：

| 路径 | 内容与处理方式 |
| --- | --- |
| `build/experiments/` | 原始实验会话（清理后约 0.7 GB）；2026-10-29 已删除两个大体积会话，摘要见 `build/validation/experiment-archive-20261026/`；另行备份 |
| `build/validation/`、`build/setup/` | 验证报告、环境信息及网络规则所有权状态，保留 |
| `build/logs/startup/` | 三个 Python 入口的阶段状态与启动日志 |
| `build/archive/` | 整理前快照、旧环境恢复备份，保留 |
| `build/tmp/`、`build/cache/` | 可重新生成的测试临时文件与缓存 |
| `build/test-results/` | 统一检查生成的 pytest 报告；CI 按平台保留为构建附件 |
| `ros2_ws/build/`、`ros2_ws/install/`、`ros2_ws/log/`、`ros2_ws/vendor/` | 本地 ROS 构建和依赖目录，Git 忽略 |

以下路径只存在于本机，由 `.gitignore` 忽略：保留磁盘内容，不上传版本库，也不作为安装或运行依赖。

| 路径 | 内容 |
| --- | --- |
| `.serena/` | 本机 AI 工具的项目索引与缓存 |
| `.codex/`、`.agents/` | 本机 AI 工具工作目录与项目内技能 |
| `config/rm65_dls_calibration.json` | 历史控制器标定快照，现行 Servo 不自动加载 |

汇报与论文产物不纳入版本库：`.gitignore` 已忽略 `*.pptx`、`*.ppt`、`*.pdf`、`*.docx` 与 `deliverables/`。2026-10-29 已删除仓库内的组会 PPT、论文 PDF、调研汇报成品及其制作素材；后续需要交付时在仓库外重新生成，本仓库只保留生成工具与文字记录。

只读网络探测 `scripts/tools/check-lan-reachable.ps1` 被本机 SSH 配置引用，不作为旧控制脚本删除。`.codex/`、`.serena/` 和编辑器设置保留在本机。

开发统一检查执行 `python -X utf8 scripts/tools/check_repository.py`，依赖与检查范围见[贡献指南](../CONTRIBUTING.md)；原 `python -B -m pytest -q` 继续可用。ROS 构建与仿真检查见[ROS 工作空间](../ros2_ws/README.md)。历史源码不纳入安装、同步或默认测试，也不恢复为备用控制链。
