# RM65 Studio 桌面控制台

日常只需运行 `python start.py`。窗口打开时不查询网络、连接机械臂或启动 WSL；任务由按钮明确触发。旧中文入口、`.cmd` 与两个 PowerShell 快捷启动脚本已按用户要求删除。

## 安装与使用

```powershell
cd D:\HDU-EILab\vr-teleop-rm65
python -m pip install -e ".[desktop]"
python start.py
```

桌面库使用 CustomTkinter 6.0.0，需要 Python 自带的 Tk；本机 Windows Python 已确认可用。不会自动安装或重建 ROS / WSL / 板端环境。

| 页面 | 操作 |
| --- | --- |
| 仿真实验 | 无手柄仿真、PICO 仿真；每种均有实际启动和离线预览按钮；服务就绪后可打开现有无手柄网页 |
| 真机连接 | 启动/复用只读会话，查询真实反馈或 PICO 输入；正式执行须选现场验收文件并手动输入原有确认口令 |
| 连接设置 | 板端地址、远程目录、控制器/反馈 IP、WSL 名称、PICO 本机 IP 和 RViz 开关；仅本次窗口有效 |
| 运行日志 | 显示本次子进程实时输出；可清空显示、打开现有启动日志目录 |

同一窗口仅运行一个任务。按钮“结束当前会话”只中断本次启动的进程会话，等待退出后才能发起下一任务；关闭活动窗口时先询问是否结束任务。界面显示的是任务进程状态，不能据此认定机械臂已静止，真实停止按现场反馈与急停流程确认。

## 同一入口的终端方式

```powershell
python start.py --cli                 # 原交互菜单
python start.py --check-only          # 仅打印菜单，不打开 GUI 或控制环境
python start.py sim                   # 无手柄仿真
python start.py pico                  # PICO 仿真
python start.py real                  # 真机子菜单
python start.py pico --check-only     # 离线预览
python start.py sim --rviz            # 仿真时显示 RViz
```

显式模式保留原 Python 选项，正式执行仍通过同一现场验证。`teleop.py` 是底层控制栈入口；`start.py` 负责日常界面和启动编排。

## 2026-10-31 开源项目调研与实际复用

| 项目 | 核对结果 | 本项目处理 |
| --- | --- | --- |
| [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) | MIT；原生 Python 桌面组件，官方提供侧栏、表单、文本框及可缩放布局示例 | **已采用**：固定依赖 6.0.0，复用真实组件和官方侧栏布局模式，不再自行绘制通用控件 |
| [PyServoArm-6DOF](https://github.com/Salim-Ammar/PyServoArm-6DOF) | MIT；相似的六轴机械臂桌面 GUI，也使用 CustomTkinter；实际接口是 Arduino 串口和 ESP32-CAM | 仅作为功能与界面选型参考；其协议、回位和舵机发送路径不适用于现有 RM65 控制链，未执行或复制其控制代码 |
| [PyDracula](https://github.com/Wanderson-Magalhaes/Modern_GUI_PyDracula_PySide6_or_PyQt6) | MIT；PySide6 / PyQt6 桌面模板 | 本轮无需引入另一套 Qt 运行时，未复制源码 |
| [Lichtblick](https://github.com/lichtblick-suite/lichtblick) | MPL-2.0；跨平台机器人数据可视化与诊断工具 | 适合后续独立数据观察需求，本轮未安装或替换现有可视化 |

已复用的界面来源为 CustomTkinter 的 `examples/complex_example.py`；版权与 MIT 许可原文见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。RM65 的启动适配、真机准入和会话管理属于本项目，未将其他机械臂的运动控制移植进来。
