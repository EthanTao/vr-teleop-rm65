# RM65 奇异区域保护（2026-09-19）

默认真机模式改为 `damped_ik_movej_follow`：检测风险、自动减速、阻尼逆解之后，实际发送受限的关节目标。`python teleop.py` 的检查和真机菜单均继承此默认值。

## 数据如何流动

```text
手柄增量 → 原有侧装映射与 Grip 锚点 → TCP 速度/加速度限制
  → 官方 FK + 显式工作/工具变换 → 6×6 数值雅可比
  → SVD 风险检测 → 降速与 DLS 局部关节增量
  → 限位、局部路径、实际反馈、耗时检查
  → movej_follow 关节目标 → UDP 实测反馈
```

首个目标从实测关节开始，后续从上一已接受目标继续，同时限制目标相对最新实测关节的偏差。不会调用全局 IK 选择另一套肘部构型。实际可达 FK 位姿用于更新限幅器，避免目标在保护期间持续累积。

## 风险判据与停止

- 雅可比平移部分先除以 `0.3 m`，再计算 `σ_min/σ_max`。比例低于 `0.04` 开始降速，低于 `0.01` 为危险区。这与旧版未归一化 URDF 雅可比的阈值不能混用。
- J3、J5 距零位小于 `15°` 开始降速，小于 `5°` 为危险区；关节机械限位预留 `5°` 余量，已在余量区内时允许退回。
- 阻尼随风险增大；候选关节增量先限速，平滑变化，再按协议 `0.001°` 量化并检查。不是给原始末端目标加一个风险标签后照常发送。
- 危险区阻止继续深入，检查局部路径的四个有序采样点并禁止 J3/J5 穿越零位。满足所有限制的退出方向可低速通过；不能承诺任意手柄反向动作都能退出，精确奇异姿态有无法实现的末端方向。
- `[DLS] hold_*` 会请求软停止，清空已接受关节目标和限幅器速度，并等待实测静止后重新计算。单纯 HOLD 不锁存故障；停止未确认、反馈失效、帧不匹配或计算超时仍会锁存。
- 正常 B 回位、自检、故障解锁后重新握 Grip 都经过同一发送门槛。B 解锁不会消除奇异姿态，也不会绕过仍然存在的控制器报警。

这里检查的是离散局部关节路径。`movej_follow` 的实际插值和停止过程由控制器执行；没有提供碰撞检测、自动换肘姿态、全局绕路或实测停止距离保证。

## SDK 与坐标系

默认模式要求运行容器安装兼容的睿尔曼 API2 Python SDK，使用 RM65-B 官方 FK。缺少 SDK 时直接拒绝启动，不回退到 `movep_follow`。官方 SDK 接口要求关节输入为度，`flag=0` 返回 `[x,y,z,w,x,y,z]`；见[官方算法接口文档](https://develop.realman-robotics.com/en/robot/apipython/classes/algo/)。内部控制与测试统一使用弧度、米和 `wxyz` 四元数。

配置关系为：

```text
T_work_tcp = T_work_base × T_base_flange(q) × T_flange_tcp
```

`--dls-work-from-base` 和 `--dls-flange-to-tcp` 各接受七个数 `x y z qw qx qy qz`，平移单位为米。省略时是单位变换，即假设官方 FK 的基座/法兰帧就是控制器使用的工作/TCP 帧。装有灵巧手或使用自定义工作坐标系时，应填写现场已有的正确变换；不要用单个位姿强行对齐来代替标定。

启动和发送前要求 FK 与同帧 UDP TCP 相差不超过 `5 mm / 2°`，不符即拒绝。这个检查能发现明显不一致，不是标定正确性的充分证明。

## 验证顺序

先运行一键菜单 **2（Dry Run）**，或在容器中运行：

```bash
python scripts/hardware/teleop_realman_rm65_safe_hardware.py \
  --arm-host 192.168.10.18 --dry-run --log-motion-debug \
  --motion-log-path /workspace/logs/dls-dry-run.jsonl
```

Dry-run 执行同一套计算与检查，但不发送运动目标或停止命令。真机保持不动时，连续远移手柄会触发“目标与实测关节偏差超限”，这是预期门槛，不表示映射失败。

记录中 `command_xyz` 是进入 DLS 的末端目标，`joint_candidate_rad` 和 `dls_achieved_xyz` 是检查后的候选关节及可达末端位置，`joint_target_accepted` 表示本地接受；不代表机器人已经执行到位。查看 `dls_status`、风险比例、反馈年龄和计算耗时，再与 UDP 实测对比。

完成坐标系核对、目标板计算时序与 dry-run 检查后，再在有急停、净空和现场监护的条件下做低速、小范围验证。默认每周期预算为 `20 ms`，计算超预算拒绝发送；本机离线测试不能证明目标板满足这个周期。

旧模式必须同时显式选择 `--motion-command movep_follow`（或 `movel`、`official_ik_movej_follow`）及 `--no-enable-singularity-avoidance`，它们不提供本页 DLS 保护，不作为遇到报错时的自动回退。

仿真仍为 Placo / 官方连续 IK 两个后端；共享的映射与官方适配器已做回归，但 Meshcat 尚未接入此 DLS 后端，不能把原仿真结果当作新真机路径验收。
