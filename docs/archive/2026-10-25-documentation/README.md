## 更正的旧说明

这些是依据当前本地源码或文件状态作出的文档更正，不是功能修改，也不是新实验结果：

- 当前同步器为argparse + ssh/tar + 远端清单；旧tyro/rsync、每次全量同步描述不再适用。
- shared-dls已接入；Placo默认启用关节和任务限速；Home预检及平移包络的入口/核心默认值不能混用。
- 工具变换省略时读取控制器，work变换仍需正确显式配置；普通入口Dry Run异常/退出可能发安全停止，区别于禁发停止的历史基准。
- 当前有2个URDF和14个STL；真机轴向表已有9月26日定性观测，但还缺完整符号定案。
- EMA增大α会减弱平滑；Grip力度不是调速旋钮；示例改为CLI布尔开关形式。
- `docs/research/` 已被既有工作树删除，本次不恢复；现有研究笔记和演示是研究导航入口。
- 日期基准只证明当时条件下的计算/准入时序，不扩展到后续版本或真实运动验收。
