# 仓库结构与文件职责

整理日期：2026-10-03。目录树来自整理后的实际文件；`build/` 展示用途目录，本机工具状态与 Git 元数据展示到目录层级。

## 从哪里开始

| 任务 | 位置 |
| --- | --- |
| 启动仿真、Dry Run、真机或同步 | [`teleop.py`](../teleop.py)，操作见[项目首页](../README.md) |
| 修改 XR 输入、映射或数据采集 | `xrobotoolkit_teleop/common/`、`xrobotoolkit_teleop/utils/` |
| 修改真机控制与实验记录 | `xrobotoolkit_teleop/hardware/`；共享核心 `RM65ControlCore` 位于 `realman_rm65_safe_teleop_controller.py` |
| 修改仿真 | `xrobotoolkit_teleop/simulation/`，shared-dls 使用同一控制核心与虚拟反馈 |
| 查找入口、预检、分析或安装工具 | [脚本索引](../scripts/README.md) |
| 核对参考参数与现场标定快照 | [配置说明](../config/README.md) |
| 了解架构、操作与安全边界 | [文档索引](README.md) |
| 追溯改动和验证层级 | [日期工作日志](logs/README.md) |
| 查找模型 | `assets/realman/RM65-official/`、`assets/realman/RM65-B/` |
| 运行回归 | `tests/`；`python -B -m pytest tests -q` |

## 归类规则

- `xrobotoolkit_teleop/` 放可导入的核心库，`scripts/` 放运行入口与手动工具，`tests/` 放自动回归。历史控制器实现集中在 `hardware/legacy/`，现有兼容入口保持原路径。
- `assets/` 保存两个 RM65 模型及网格；`config/` 区分入库参考参数与本机标定快照；`docker/` 保存部署配置。
- `docs/` 根目录维护核心工程文档、实验记录说明和导航；日期日志归 `logs/`，离线快照归 `data/`，计划归 `plans/`，研究材料归 `research/`，历史原文归 `archive/`。
- `build/experiments/` 保存实验会话；`validation/` 保存验证与基准结果；`demos/`、`group-meeting/` 保存演示与组会材料；`archive/` 保存整理备份；`cache/`、`tmp/` 保存缓存和临时文件。`build/` 整体被 Git 忽略，有研究价值的产物需另行备份。
- `.agents/` 中的项目技能随仓库保存；`.codex/`、`.vscode/` 是本机工具目录，Git 忽略。
