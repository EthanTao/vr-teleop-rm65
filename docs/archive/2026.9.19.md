# 2026-09-19 工作日志

## 奇异区域保护核查与修复

### 背景与证据边界

用户报告：末端跟随方向基本正确，但 B 解锁后重新握 Grip 时，肘部出现突然大幅转动；所贴历史运行日志包含控制器错误 `4099`、`4107`。这些现象不能单独证明每一次关节突转的根因。用户要求按“提前检测、自动减速、阻尼 IK、限制深入并允许受限退出”的思路核查已有版本并直接修改。

本次核查确认已有代码存在五个问题：

1. DLS 只预测关节变化，实际仍发送原始笛卡尔目标，无法约束控制器内部逆解分支。
2. 固定幅度探针能从 J5 正小角穿过零位到负侧，再被误判为退出。
3. HOLD 仅冻结目标而未取消在途轨迹；同时缩小减速度，会延长停止过程。
4. 结构 URDF 的法兰/基座雅可比直接处理控制器工作/TCP 帧目标，缺少一致的帧语义。
5. B 正常回位和自检没有共用完整的奇异保护发送门槛。

### 已实施

- 默认真机模式改为 `damped_ik_movej_follow`，一键菜单 2/3 通过既有入口继承新默认值。启动打印模式与 dry-run 状态。
- 新增 `damped_ik.py`：官方 FK、显式工作/工具帧变换、中心差分雅可比 `(6,6)`、SVD 降速和阻尼局部 IK。线性雅可比除以 `0.3 m` 后再使用比例阈值 `0.04 / 0.01`；J3/J5 阈值为 `15° / 5°`，退出请求比例 `0.10`，最小比例 `0.05`，最大阻尼 `0.08`。
- 实际下发的是检查后的六关节目标 `(6,)`，不再只用 DLS 做预测。输入输出内部使用米、弧度、`wxyz`；按协议 `0.001°` 量化后再校验。
- 新运动段从实测关节开始，后续延续上一已接受目标；保留相对最新实测反馈的单周期偏差预算。失败、HOLD、松 Grip、重新建锚点清除旧目标，避免跨段沿用。
- 小幅局部方向检测替代跨零探针；四个有序路径采样点检查风险，不允许 J3/J5 穿零。机械限位预留 `5°`，已在余量内时允许退回。退出仍须符合全部约束，不能保证任意方向均可退出。
- HOLD 请求有确认的软停止，清空目标/速度参考并等待 UDP 实测静止。停止未确认锁存故障。降低速度上限不再同步降低笛卡尔制动加速度。
- 正常 B 回位、自检、解锁后的 Grip 跟随共用发送门槛；新段若机械臂仍在停止中，先等静止。回位和 Grip 松开也检查停止确认。
- 增加 `--dls-work-from-base`、`--dls-flange-to-tcp` 七数位姿变换参数；默认单位变换。启动和发送前核对官方 FK / UDP，超过 `5 mm / 2°` 拒绝。没有使用单个位姿自动对齐来掩盖模型/坐标系问题。
- 官方算法适配器增加 `fk_only=True`，DLS 不依赖 `rm_algo_ik_remote` 初始化；原官方 IK 与仿真调用默认行为保持兼容。缺 SDK 不自动回退。
- 发送前重新读取反馈，计算超过控制周期拒绝发送；可达 FK 位姿和速度重新写入限幅器，避免不可达目标积累。周期内缓存 FK/SVD 结果，降低重复计算开销。
- 运动日志增加 DLS 状态、预测比例、阻尼、候选关节、本地接受标记和可达 FK。`command_xyz` 仍表示 DLS 输入目标，不能当作实际执行反馈。
- `singularity_avoidance.py` 保留离线结构分析用途并修正局部探针，不再负责批准真机运动。历史模式须显式关闭保护开关，不能声称仍有 DLS 保护。
