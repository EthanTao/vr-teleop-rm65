# RM65 本体参数与遥操作安全含义

> 官方来源：[睿尔曼《RM65系列参数及D-H模型》](https://develop.realman-robotics.com/robot4th/robotParameter/RM65OntologyParameters/)  
> 本地同步日期：2026-08-31。设备铭牌、控制器版本和最新官方文档优先于本页快照。

本文只记录与本仓库的运动学、仿真和真机遥操作直接相关的参数。它不能替代现场碰撞检查、负载核算或安全评估。

## 1. 基础参数

| 参数 | 标准版 RM65-B | 六维力版 RM65-6F |
|------|---------------|------------------|
| 自由度 | 6 | 6 |
| 工作半径 | 610 mm | 627 mm |
| 有效负载 | 5 kg | 5 kg |
| 自重 | 7.2 kg | 7.3 kg |
| 重复定位精度 | ±0.05 mm | ±0.05 mm |
| TCP 最大线速度 | ≤1.8 m/s | ≤1.8 m/s |
| 安装角度 | 任意角度 | 任意角度 |
| 工作温度 | 0～45 ℃ | 0～45 ℃ |
| 工作湿度 | 25%～85%，无结露 | 25%～85%，无结露 |

“任意角度安装”表示本体允许侧装等安装方式，不表示任意关节姿态都安全，也不表示控制软件可以忽略重力方向、碰撞和奇异点。

## 2. 关节范围与最大角速度

| 关节 | 官方运动角度范围 | 官方最大角速度 |
|------|------------------|----------------|
| J1 | -178°～+178° | 180°/s |
| J2 | -130°～+130° | 180°/s |
| J3 | -135°～+135° | 225°/s |
| J4 | -178°～+178° | 225°/s |
| J5 | -128°～+128° | 225°/s |
| J6 | -360°～+360° | 225°/s |

仓库中的官方 URDF 将这些角度近似写成弧度限位，例如 J1 为 `[-3.11, 3.11]`、J2 为 `[-2.27, 2.27]`。URDF 限位用于仿真求解约束；真机仍以控制器的实际软限位、故障状态和现场安全边界为准。

## 3. RM65 系列 MDH 参数

官网采用 Modified Denavit-Hartenberg（MDH，改进 D-H）模型：

| i | a(i-1) / mm | alpha(i-1) / ° | d(i) / mm | theta(i) offset / ° |
|---|------------:|----------------:|---------:|--------------------:|
| 1 | 0 | 0 | 240.5 | 0 |
| 2 | 0 | 90 | 0 | 90 |
| 3 | 256 | 0 | 0 | 90 |
| 4 | 0 | 90 | 210 | 0 |
| 5 | 0 | -90 | 0 | 0 |
| 6 | 0 | 90 | d6 | 0 |

官网给出的角度关系为：

```text
模型角度 = 关节角度 + offset
```

> ⚠️ **本表按字面无法直接建链（2026-09-18 记录）**：按 MDH 定义，第 i 行的 `alpha(i-1)` 把 `z(i-1)` 转到 `z(i)`，而本表 `alpha(0) = 0` 会推出 `z1 ∥ z0`，即 J1 与 J2 同轴，与 RM65 的实际结构矛盾（J2 应与 J1 垂直）。因此该表的 α 列疑似错位或转抄有误，需按官方页面原文核对后再使用。
>
> 需要可执行的运动学模型时，改用仓库内官方 URDF 的关节链（`assets/realman/RM65-official/urdf/RM65-official-arm.urdf`，每关节固定 origin + 绕本地 z 旋转）：其连杆量级与本表一致（`d1 = 240.5 mm`、`a2 = 256 mm`、`d4 = 210 mm`），并且给出了本表缺失的末杆偏置 `d6 = 112.03 mm`。`xrobotoolkit_teleop/hardware/singularity_avoidance.py::RM65_CHAIN` 即该链，并有测试逐项复核。

`d6` 随 RM65-B、RM65-6F 及带 `-V` 的具体型号变化。当前网页的文本内容没有完整呈现各型号数值，因此本页不猜测；做 FK、IK 或修改 URDF 前，必须按设备具体型号核对官方模型或尺寸图。

官网还给出了基于 CAD 设计值的连杆质量、质心和惯量。由于网页文本中的部分单位没有完整呈现，本仓库不将该表直接转抄为可执行动力学参数；动力学仿真应使用型号匹配且单位完整的官方模型文件。

## 4. 工作空间不是安全空间

官方说明 RM65-B 的运动范围近似为半径 610 mm 的球体，但需要排除基座正上方和正下方的圆柱区域；可操作度较好的区域整体呈环状。

因此：

- 610 mm 或 627 mm 是本体工作半径，不是“末端在该球体内就一定可达、无碰撞”。
- 靠近最大伸展、基座轴线、关节极限或障碍物时，即使几何位置仍在工作半径内，也可能不可用。
- 本项目真机接口的 XYZ bounds 是独立的软件安全边界，不能直接用本体最大工作半径替换。
- 负载 5 kg 是额定有效负载；工具和工件的质心偏置还需结合官方负载曲线核算。

## 5. 官方列出的四类奇异点

| 类型 | 官方判据或特征 | 遥操作风险 |
|------|----------------|------------|
| 肩部奇异 | J5/J6 轴线交点进入通过 J1 轴线且平行 J2 轴线的平面 | 末端小幅运动可能要求部分关节快速变化 |
| 肘部奇异 | `q3 = 0` | 手臂接近伸直，部分方向可操作度下降 |
| 腕部奇异 | `q5 = 0` | J4/J6 轴线平行，腕部角度可能发生大幅重分配 |
| 边界奇异 | 最远端附近同时满足 `q3 = 0`、`q5 = 0` | 接近最大伸展，末端运动方向受限 |

官网把 `[0, 0, 0, 0, 0, 0]` 列为边界奇异示意点。该数组只是六个关节角的示例，单位为度；它不是侧装 RM65 的安全 Home Pose，也不能直接写入启动参数。

## 6. 本项目中的使用规则

### 仿真

- `scripts/simulation/teleop_rm65_sim.py` 必须通过 `--home-joint-deg J1 J2 J3 J4 J5 J6` 接收六个现场确认的关节角，单位为度。
- 六个值会转换为弧度并接受 URDF 关节限位检查。
- B 键在默认 3 秒内插值回该 Home Pose。
- Home Pose 除满足关节限位外，还必须在侧装环境中确认无自碰撞、无外部碰撞并远离奇异点。

### 真机

- 推荐入口 `scripts/hardware/teleop_realman_rm65_placo_hardware.py` 不使用 URDF/Placo 求真机 IK；RM65 控制器处理 `movel` 目标。
- 程序连接后记录启动时的实测 TCP 位姿，B 键默认用 3 秒返回该启动 TCP 位姿。
- 启动前必须人工确认当前实体姿态安全；危险姿态一旦被记录为启动位姿，复位同样会返回该危险姿态。
- 关节限位、XYZ bounds、XR watchdog、反馈/跟踪误差、故障锁存和停止逻辑是相互独立的保护，不应因工作半径或安装方式参数而删除。

## 7. 变更这些参数前的核对清单

1. 确认实体型号：RM65-B、RM65-6F 或带 `-V` 的变体。
2. 确认安装方式和基座坐标系，侧装不能沿用桌面安装方向假设。
3. 用示教器低速到达候选 Home Pose，检查自碰撞、环境碰撞和线缆余量。
4. 检查候选姿态与 `q3 = 0`、`q5 = 0` 及最大伸展区域的距离。
5. 在仿真中核对 URDF 关节范围，再以低速度、小范围完成真机验收。
6. 若要修改 MDH、惯量或在线运动协议，先取得与控制器/机械臂版本匹配的官方资料。
