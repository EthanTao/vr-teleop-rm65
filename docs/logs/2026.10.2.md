### 行为与数据原则

- 全程自动记录，不依赖按 m；m 仅标记人工观察。非交互终端照常采集。
- 输入、限速候选、准入接受、发送和 UDP 执行反馈分别记录。未计算/未接受/未发送保持 null/false，不能把旧值当本周期结果。
- `sendall_completed` 是 socket 写入结果，不能代替实际执行证据。Dry Run 接受只表示虚拟准入。
- 每个反馈快照内部所有通道来自同一 UDP 帧；不同使用时点保留不同快照，重复 sample ID 明示同一帧复用。
- 控制循环只做结果复制和非阻塞入队。周期与 console 队列、事件队列都有限容量；后台写入/序列化，退出后摘要/校验。日志失败使记录“不完整”，不进入运动保护判据，也不盖掉入口异常。
- 摘要分列各层路程、XYZ 净位移、Grip 时段、保持原因、周期/反馈统计；往返动作不用净位移比判断跟随。分位数注明末尾最多 4096 个有效样本。
- Git 提交读取不可用时保存 null，运行关键源码 SHA-256 仍保留；启动器另外保存本机代码身份，避免把 dirty 或无 Git 的容器代码假定为某个提交。
