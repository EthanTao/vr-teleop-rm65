## UR5 与当前 RM65 手柄遥操作逻辑比较

- 用户要求分析 `HDU-EILab/ur5-teleop`，随后与本仓库比较。UR5 阅读快照为 `8691bfae256d9f48db60eeeca56e243b043d1fea`；RM65 本地基线为 `3d8c6cc`，开始时工作树干净。本轮仅新增本条分析记录，未修改运行代码、配置或安全行为。
- 两者都用 Grip 锁存实测 TCP 和手柄位姿，按相对位姿生成末端目标。UR5 通过 RTDE 将目标交给控制柜 `get_inverse_kin + servoj`；RM65 当前使用 InputAdapter → PoseTracking → MoveIt Servo → JTC → 受控设备桥/驱动，旧自研 DLS 不在运行链中。
- 映射差异：UR5 锁存头显水平朝向并补偿安装偏航；RM65 使用固定 `[[0,1,0],[1,0,0],[0,0,-1]]`。两者均不是持续头显相对位姿控制，不能据此声称补偿操作者身体平移。
- 参数以随附实际配置为准：UR5 平移 1.8、旋转 0.7、Grip 0.8/0.6，软阈值持续 0.25 s 可接通；RM65 `teleop.yaml` 平移/旋转均 1.0、Grip 0.2/0.15、单段旋转上限 45°。RM65 Python 类中的旋转 0.25/上限 0.20 rad 默认值被 launch 配置覆盖。
- UR5 逐步限制目标变化、裁剪 XYZ 盒，并在输入恢复或目标领先过多时重新建立锚点；RM65 输入跳变拒绝后要求释放 Grip，连续旋转处理避免 ±π 分支翻转。PoseTracking 前以实测 TCP 截断误差，不重设输入锚点；配置的 0.15 m/s 与位置增益 20 对应 7.5 mm 误差界，0.25 rad/s 与角增益 8 对应 0.03125 rad，均不是实体速度保证。
- RM65 设备准入另外检查相邻命令步长、相对实测反馈的领先预算、同包真实反馈及停止确认；正常松 Grip 请求软停，失败升级硬停，原生 watchdog 覆盖命令/反馈超时。UR5 机器人端 watchdog 默认关闭，idle 分支仅停止继续调用 servoj，不能据说明声称断网必然进入 idle 或松 Grip 等同硬件急停。
- 交互差异：UR5 supervisor 接 Trigger 夹爪、B 录制/保存后倒计时 Home；RM65 可选手流程使用 Trigger/A/B 任务预设，真实写入仍受现场配置门控，当前没有自动 Home。不能直接复用 UR5 按键分配。

- 来源：https://develop.realman-robotics.com/robot/apipython/classes/algo/ ；https://develop.realman-robotics.com/robot/apipython/classes/movePlan/ 。本轮为官方文档和本地源码只读核对，未运行官方 IK、未连接设备或发送运动指令，未修改运行代码。
