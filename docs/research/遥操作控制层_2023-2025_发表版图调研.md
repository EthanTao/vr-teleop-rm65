### 2.2 判断

- **主流阵地**：ICRA / IROS / T-RO / T-Mech / RA-L / Humanoids，加运动学专会 ARK。**奇异点单独成篇很少**，多数是作为 MPC/CBF/QP 框架中的约束项、或速度级 IK 控制器设计的一部分出现。
- **经典 DLS/伪逆线已饱和**：OpenAlex 标题检索 "damped least squares" 2023–2025 仅 17 条，且多为地球物理/光学/电机领域；机器人相关的落在 IEEE Access、IJARS、ACM 会议集、J. Phys. Conf. Ser. 等非优先阵地。**再写一个自适应阻尼公式很难进 ICRA/T-RO**——必须绑定实时优化、CBF、学习式 IK、遥操作手感或全身控制。
- **近三年被当作"新问题"的点**：(a) **learning-based IK 的解连续性/安全性**（Humanoids'23 学避障、ICRA'24 CppFlow 生成式 IK、IKSel'25 反过来质疑学习式 IK）；(b) **全身/层级控制的奇异鲁棒 + 任务切换平滑**（ICRA'24 平滑激活矩阵、T-RO'24 HIMPC 带可行性证明）；(c) **CBF 化奇异约束**（IROS'25）；(d) **teleop 奇异手感**（J-PARSE 主张"embrace singularity"、Bunny-VisionPro、2026 年 IEEE Access 已出现"触觉反馈 + 奇异管理"的 VR 遥操作框架）。
- **与本项目最贴近的空白**：**6 自由度非冗余工业臂上"速度级 DLS 与位置级 IK 混用的跳变/连续性判据"没有顶会新文**；seed 选择与在线连续性判据目前主要由预印本和低层级期刊承载。可直接引 IKSel（seed 策略）与 cuspidal-6R（连续关节路径）两篇预印本。
- **落点判断**：想发这条线，最现实的是 **ICRA/IROS/RA-L**（都非 CCF A）；若要把"奇异点处理 + 遥操作手感"做成 CCF A，唯一现实路径是包装成**人因/VR 研究**投 IEEE VR / TVCG / CHI（见 §3 与 §7）。

### 3.2 直接回答："有没有论文专门研究映射矩阵/参考系设计对操作性能的影响？"

**结论：有，但非常薄，而且分散在三个不相干的口子里。**

1. **设计参数研究**：`Decision of impedance-based scaling factor for workspace mapping`（2023）专门研究缩放系数怎么定；`Mapping for stable bilateral teleoperation…`（IJSS 2024）把映射当作稳定性设计变量。这两条最接近"映射设计 → 系统性能"的因果研究。
2. **映射可信度**：`Conformalized Teleoperation`（RSS 2024）不比较两种映射矩阵，而是给映射配一个**校准过的不确定性区间**——这是目前对"映射质量"最严谨的量化处理，也顺带提供了**输入不确定性检测**的机制（与 §5 的输入异常检测天然衔接）。
3. **HCI 侧的经典范式**（参考系 / control-display gain 作为自变量做被试内设计）在机械臂遥操作上**本轮没有抓到 2023–2025 的 CHI/UIST 论文**。考虑到 ACM DL / IEEE Xplore 在本环境被拦截，这里**标「待核实」**，不能断言"不存在"。

→ **对项目的直接含义**：你的侧装映射矩阵（`R_HEADSET_TO_WORLD_RM65_SIDE_MOUNT*` 三套）与"逐轴实测判定"正好落在这个空白上。若把它做成**被试内对照实验**（不同参考系/增益 × 任务类型 × 主观量表 + 客观指标），在 HCI 侧是标准可发表形态（**CHI / UIST / IEEE VR / TVCG = CCF A**），而在机器人侧只能进 RA-L / IROS。

|---|---|---|
| 研究问题 | 人能不能理解这个映射、学得快不快、累不累、信不信任 | 这个映射能不能把任务做完、稳不稳、快不快 |
| 方法 | 被试内/被试间**用户研究** + 量表（SUS、NASA-TLX）+ 半结构访谈 | 系统实现 + 定量任务实验 |
| 指标 | 主观负荷、偏好排序、可用性、成功率、耗时 | 任务成功率、完成时间、跟踪误差、抖动/节拍 |
| 例证 | **EVE (UIST 2024)**：N=14 用户研究 + SUS + 偏好排序 + 成功率 | **Conformalized Teleoperation (RSS 2024)**：覆盖率/不确定性 + 任务成功率，不做量表 |
| 门槛 | 需要真实用户、伦理审批、统计功效分析；纯工程实现不收 | 需要真机 + 与基线可比 + 消融 |

**这条分野是成立的**（由上面两篇的代表性样本直接支撑），并且它决定了"能不能进 CCF A"：**同一份映射工作，做成"人因实验"就能投 CHI/UIST/IEEE VR/TVCG（A），做成"系统实现"就只能投 RA-L/IROS（非 A）。**

**三处必要修正**：① 界线正在模糊——GELLO（ICRA）做了 12 人 × 5 任务用户研究，HRI 的论文也开始报成功率与效率；② 证据强度不对称——**只有 HCI 侧把参考系当自变量**，robotics 侧连消融实验都罕见；③ 两边统计都弱——HCI 被试常 5–21 人且任务常被简化为屏幕上的方向判断，robotics 系统完整但 N 小或无统计检验。

### 3.5 术语、待核实项与对项目的三条直接含义

**术语（决定你能不能搜到文献）**：你说的"映射矩阵"在英文文献里几乎不叫 *mapping matrix*。robotics 侧的检索词是 **control frame / coordinate frame / control coordinate system / retargeting / workspace scaling**；HCI 侧的检索词是 **control-display mapping / frame of reference / mental transformation**。用中文或 "mapping matrix" 直译检索，命中率极低。

**对项目的三条直接含义**：
1. **A1（IEEE Access 2024）是唯一可当作"映射矩阵设计方法论"引用的文献**：它把"每个输入轴对应远端哪个方向"当成可枚举的设计空间——正好对应 `docs/RM65参数与坐标系.md` §14 的逐轴判定表。建议把该表重新表述为"控制坐标系选择"问题，与 A1 的三条设计准则对齐。
2. **A2 / A4 支持"先冻结矩阵、用可视化辅助建立心智模型"的路线**：A2 说心理变换越少越好（⇒ 优先选不需要操作者做镜像/旋转心算的轴向），A4 说映射本身可以被可视化加速学习（⇒ 仿真里叠加"手柄参考系/工具端幽灵"比继续改矩阵更划算）。
3. **B2 给出"clutch + 速率控制"的现成设计模式**：工作空间内用直觉的姿态映射，越界后切换为由输入力决定的速度控制来重定位——与项目当前"增量式锚点 + 限速 + 边界保护"的架构同源，可作越界行为的参考设计。

### 4.2 判断

- **稳定接收这条线的 venue**：TCST（能量反射/TDPA 最稳主阵地）、T-RO（无源 + 硬约束/多机系统集成）、T-Haptics（共享自主、保守性—透明度权衡）、RA-L（设计+实验/用户研究）、WHC / Haptics Symposium（模型介导与感知驱动优化）、ICRA（无源理论的**实现层瓶颈**，如执行器能力）、IFAC-PapersOnLine（传输整形）。
- **"经典问题做完了"= 否，但机理已封闭**。2023–2025 在发的是三件事：(a) 拿无源判据的**保守性换性能**；(b) 让理论在**真实硬件约束**下成立；(c) 把评价指标从信号层搬到**人的感知层**（QoP、力反馈感知评测）。
- **学习+无源混合**目前主要在预印本与偏应用会场（arXiv eess.SY、CASE、RO-MAN），顶刊正式接收很少——题新但缺可信基准，是机会也是风险。
- **对本项目**：只做"加个能量罐让机械臂不抖"**不足以**成为独立贡献；若要碰这条线，最现实落点是 **RA-L / TCST**，其次是 WHC / Haptics Symposium。注意 **T-Haptics、TCST、RA-L 都不是 CCF A**。

### 5.5 输入异常检测（人手抖动 / 主端跳变 / 丢包）—— 被证实的空白

- **"故障锁存（latching）"在学术文献中检索命中为 0**：它是工业控制器（UR/KUKA/睿尔曼）保护性停止与复位规范里的工程约定，不是被研究的对象。要写成论文必须重新表述为学术问题（"带状态记忆的不可自恢复安全集""安全监视器可复位性形式化"）。
- **主端跟踪跳变检测、丢包导致的指令不连续检测**：**未检索到任何以之为核心贡献的论文**。
- `tremor + teleoperation` 在 arXiv 全库仅 4 条且偏外科；代表性 3 篇：Sensors 24(22):7359（2024，深度学习预测并消除生理性手抖）、Applied Sciences 13(2):890（2023，CNN + 广度增量学习自适应滤波抑抖）、ISA Transactions（2025，递归奇异谱分析实时**分离**抖动与有意运动）。
- 与"丢包→指令不连续"最接近的工具性工作：**TeleSim**（arXiv:2507.04425，仅预印本）用 OMNeT++ 精确控制带宽/时延/抖动/丢包，最差网络下完成时间 +221.8%、成功率 −64%。

### 5.6 判断

- **门槛规律**：应用增量 → RA-L / ICRA / IROS / 人机会议；理论增量（时延/不确定下的新构造与证明）→ ECC / CCTA / IFAC / CDC / ACC；方法与范式增量 → RSS / CoRL / T-RO。
- **单纯"限幅 + 锁存 + 停机状态机"发不了 RA-L/ICRA**，天花板是 CASE / AIM / ICRA workshop / IEEE Access / Sensors / Machines。要有硬增量：缩放的稳定性或最优性证明、停止距离的可证明上界、或大规模真机数据的统计显著优势。
- **可走的 CCF A 路线**：把它包装成 runtime verification / 安全监视器形式化 → **CAV（A 类会议）或 IEEE TSE（A 类期刊）**；这是本子方向唯一现实的 CCF A 通道。
- **差异化角度**：把"VR 手柄输入流 → 限幅 → IK → 真机"链上的**输入异常检测 + 安全集锁存 + 可复位性**做成统一框架，用真机故障注入（人为丢包 / 手柄跳变 / 反馈超时）做定量评估。该组合在现有文献中未见。
- **最新对标（2026，超出窗口）**：`A Safety-Aware Shared Autonomy Framework with BarrierIK Using Control Barrier Functions`，**ICRA 2026** —— CBF 放在 **IK 层做 post-blend 安全** + **VR 遥操作用户研究**，并论证"两个各自无碰的指令线性混合后仍可能不安全"。

### 6.3 判断

1. **分布是"倒挂"的**：预测显示 / 时延补偿可视化 / 人因研究绝大多数落在 ICRA、IROS、RA-L、T-RO、THRI、TVCG；网络类阵地收的是另一个物种——不是"把机器人做出来"，而是"把网络资源调度出来"。
2. **网络类 CCF A 的门只对三类切口开**：(a) 通信-控制协同优化 → JSAC；(b) 时延/抖动**测量方法学** → TMC；(c) 高时延下的人因框架 + 用户研究 → TMC。三者都必须把"网络"当**研究对象**，而不是实验条件。
3. **"预测显示/时延补偿"的创新门槛已不在预测算法本身**（预测机器人自身运动是 20 年前的问题）。现在的门槛是预测**人**（操作者意图）与**环境**（动态变化），或在 HMD 管线里同时消视差与时延。
4. **真实链路实测是网络类投稿的硬入场券**（ICMRE 的 5G/Wi-Fi/以太网横向、PIMRC 的 5G SA 专网、ICCPS 的真实 5G 双边触觉）；对机器人会议只是加分项。网络类**没有一篇靠仿真网络参数（"设 100 ms 时延、5% 丢包"）进**。
5. **三个技术点覆盖不足（可作选题）**：时间同步/时钟偏移/延迟估计、jitter buffer / packet loss concealment / 自适应采样、双手与多机器人同步遥操作的通信问题——本轮均**未检索到**网络口径的 2023–2025 论文。

**三条最值得记住的结论**：
1. 想发 CCF A，**必须换赛道**：要么把机器人问题做成 HCI/VR 研究（CHI/UIST/IEEE VR/TVCG），要么做成网络研究（TMC/JSAC/INFOCOM），要么做成形式化/软件工程（CAV/TSE）。留在纯机器人 venue，天花板就是 ICRA（CCF B）。
2. **本项目的天然 A 类切入口**是 ②和⑤：VR 映射手感 + 用户研究 → IEEE VR / TVCG / CHI；真机网络链路测量 → TMC/INFOCOM WKSHPS。
3. **④中"故障锁存"与"输入异常检测"经检索是空白**——引用会难（没有现成文献可引），但也是差异化最好的地方；建议重述为"带状态记忆的不可自恢复安全集 + 安全监视器可复位性"。
