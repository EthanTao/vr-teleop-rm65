## 2. 核心决策

### 2.1 输入参考系

SDK 位姿为启动锚定世界系，原点是启动时头戴位置；头显、手柄、手势和动捕共享坐标，pybind / ROS 透传不额外变换。因此“转头必使静止手柄误动”不由该语义推出；身体平移/前倾仍会改变世界系手柄位置。

若要抗走动，应基于 `T_rel(t) = T_head(t)⁻¹ · T_ctrl(t)` 同时重建位置与姿态增量；**当前未采用**。SDK 七数格式及文档轴向矛盾见[坐标系 §7–11](RM65参数与坐标系.md)。

### 2.2 侧装映射

当前两端均用 `_HARDWARE = [[0,1,0],[1,0,0],[0,0,-1]]`；旧 `SIDE_MOUNT = [[0,-1,0],[-1,0,0],[0,0,-1]]` 没有运行引用。前者加平移 XY 取反与后者等价（历史随机 100 样本最大误差 `0.0`），**不表示旋转也等价**。当前默认 `invert_tcp_xy=False`。

映射于 2026-09-09 冻结，机器人竖立显示不改变映射；逐轴方向仍以实测为准。9 月 18 日仿真 X/Y 观测与推导互换，9 月 26 日有真机定性反馈，轴向及符号尚未完整定案。原始表见[坐标系 §14](RM65参数与坐标系.md#axis-observations)。

### 2.3 独立反馈与停止

旧路径存在 `move_v=30` 偏大、只限位置、TCP 查询阻塞发送及可绕过保护的问题。改为低速有界命令、latest-only UDP、异常锁存；缺 `joint_speed` 拒绝启动。

正常松 Grip 软停；故障硬停并锁存，需故障后的 Grip 释放和安全反馈才能重新使能，B 只复位。新段首周期以实测重建锚点，避免拿陈旧目标误报跟踪误差。Home 提示/缓冲和完整门限统一见[真机操作页](真机安全与故障处理.md)。

### 2.4 官方连续 IK

2026-09-10 新增 `rm_algo_ik_remote → 关节范围/步长检查 → movej_follow`；SDK 缺失、求解失败或非法解拒绝。仿真只用 Placo wrapper 显示，J3 有 `±5°` 排除区；真机依靠人工确认工作/工具帧和 J3 非零软限位。verified 开关不执行标定，也不写软限位。

首版每周期用 UDP seed，9 月 15 日改为首帧实测、后续上一已接受目标。“真机只发笛卡尔目标”的 9 月 9 日责任边界已过时；当前默认与官方 IK 都会发关节目标。

### 2.5 连续性与实测偏差

上一已接受目标保证命令连续，最新实测反馈约束领先量。接受表示通过本地检查和提交，不等于到位；发送失败不推进目标。松 Grip、故障或新段重建参考，不能跨段沿用。当前默认微分 IK 也遵守这一原则；跟随余量保持时另有 `_dls_seed_joint_rad` 保留命令流，避免恢复时跨余量跳变。

### 2.6 奇异保护演进

| 版本 | 改动及理由 | 验证边界 |
| --- | --- | --- |
| v1，09-18（已停用） | URDF 结构 FK / 雅可比、DLS 预测与方向门控；J3/J5 单独判断会漏肩部奇异 | 结构分析；不能批准真机 TCP 运动 |
| v2，09-19 | 实际发送受检关节目标；显式帧变换；HOLD 请求确认软停；局部路径拒绝穿零；机械限位留 5° | 本机合成 FK 与准入测试；后来由 bounded-search 改实时路径 |
| bounded-search，09-23 | 一次 Jacobian、常数时间结构守卫、有界候选，正常 14 / 最多 16 FK | 目标容器 Dry Run；不含实际执行 |
| v2.1，09-26 | 命令速度预算与反馈滞后预算分开；余量内减速、保持、持续恶化才锁存 | 现场日志归因 + 本机验证，详见当日日志 |
| v2.2，09-26 晚 | `J⁺e` 方向保持步长、方向等效增益、单侧结构守卫、公共加速度缩放 | 离线复现与差分；不冒充后续真机验收 |

v1 的五个问题：预测的关节步没有实际下发；固定幅度探针穿零后误判退出；冻结目标未取消在途轨迹；URDF 与控制器工作/TCP 帧混用；B 回位/自检未共用完整门槛。历史声称“四个问题”的计数已更正。

v2.1 的现场证据是 `0.408/0.377/0.365° > 0.360°` 反复停机，而相邻命令仅 `0.188°`；UDP 最老 `48.09 ms`。当前单周期额度 J1/J2 `0.360°`、J3–J6 `0.450°`；实测偏差额度为 3 倍，保持线为额度的 `2/3`，保持超过 `0.3 s` 或调速器介入且连续 6 周期无进展才锁存。不能把跟随误差解释为速度，也不能靠放大余量掩盖执行问题。

同轮曾将 DLS 速度除以 `dwell/dt=15`，把 J1/J2 压到 `1.2°/s`，已移除。假臂差分最大步长 `0.024° → 0.36°`、稳态 `1.19°/s → 17.3°/s`；不是实测真机速度。Placo 同轮接入默认关节速度/加速度和任务目标限速，旧“限速已回退”只描述早期实验。

v2.2 的三条证据：方向阻尼造成离线偏转 `13.8°–20.2°`、`24%–35%` 分量偏离指令；配置级全停误拒切向/退出；逐关节加速度截断使 Home 附近 ±Z 从第 0 周期不动。当前 `σ_eff/σ_max = |e|/(|J⁺e|·σ_max)` 按方向判定，阻尼参数只诊断；退出和切向仍受路径、穿零、限位、反馈等约束。精确奇异不能保证任意反向动作均可退出。

Home 是明确例外：2026-09-26 起真机入口预检默认关闭，此时走关节插值直发，保留反馈安全检查，但不经过 DLS 奇异守卫；详见[回位说明](真机安全与故障处理.md#home)。

### 2.7 遗留入口

推荐入口为 `teleop_realman_rm65_safe_hardware.py`；旧 placo 名称只转发，旧单文件只允许 Dry Run。历史实现集中在 `hardware/legacy/`，旧 dead code / superpowers 产物曾清理。兼容范围与备份路径见[交接 §6.1](项目交接.md#legacy)和[仓库结构](仓库结构.md)。

### 2.8 仿真数据与手感

Grip 联动 HDF5 episode，记录关节、末端、相对动作和 Grip，默认关闭；字段与尾帧语义见[仿真手册](仿真操作手册.md#simulation-data)。MotionFilter 用逐分量死区和 `y_t=αx_t+(1−α)y_(t−1)`，Grip 起点清历史；当前 Placo 管线再做任务与关节约束。

早期“速度限制默认关、未配 Home 时禁用 B”是当时实现；现在入口提供固定 Home，Placo 速度限制默认开。HDF5 不含相机/夹爪，也不等于后来新增的真机 JSONL 实验记录。旧数据 logger 导入错误与 URDF 限位修复细节见归档 §2.8。

### 2.9 一键启动与同步

当前 `teleop.py` 用 argparse 和 Python 标准库：同步 → 模式 → 隧道 → 启动 → 回收/清理。同步用 ssh + tar、远端清单和内容指纹；远端无清单时全量上传。旧 tyro、每次全量 rsync、仅本地缓存决定上传的说明都属于历史版本。

启动器不管理容器生命周期、不支持多机器人、不保存 SSH 密钥；同步失败退出，隧道失败告警；signal / atexit / finally 清理，隧道 terminate 超过 5 s 再 kill。两端源码指纹用于发现版本不一致，不参与运动安全判据。

### 2.10 DLS 性能：保留日期和测试条件

| 2026-09-22 旧链路 | 结果 |
| --- | --- |
| FK 次数 | 无输入 13，正常 74，历史最坏计数 222；特定路径算式 217，口径不同 |
| 正常 74 的构成 | 种子 1 + 中心差分 12 + 逃逸探测 12 + 4 个路径点 × 12 + 端点 1 |
| 裸官方 FK / 适配器 | `0.147 ms` / `1.2 → 0.385 ms` |
| 容器 DampedIK.step / 完整周期 | `89–110 → 35.6 ms` / `38.2 ms`，仍超 20 ms |
| NumPy 原语运算数 | `2695 → 559`（−79%） |

主要代价是调用内的 Python/NumPy 工作量与重复 FK 两个乘数：逃逸与路径共 60/74 次 FK（81%）；每步 6 次 Jacobian/SVD 中只有 1 次为求解本体。容器合成 Python FK `1.125 ms` 比 SDK 慢 7.7 倍；同段 Python 本机 `0.119 ms`、容器 `1.027 ms`，容器 NumPy 小操作约 `40 µs`。只优化单次或只减次数都不足以稳定进预算。

标量四元数重写、已校验元组缓存和 `(12,6)` 差分模板通过对拍：16,018 例四元数最大相对差 `0.0`，Jacobian 最大绝对差 `0.0`；本机 step `11.13 → 6.67 ms`，适配器 `0.0655 → 0.0175 ms`。曾发现高级索引 `stencil[0::2, range(6)]` 网格化缺陷，改成成对 `stencil[2*rows, rows]`。

**2026-09-23 实际落地**为保守 bounded-search：无零空间自运动、危险区不退回昂贵搜索；一次 Jacobian，正常 14 / 硬上限 16 FK，最多 3 个候选，18 ms 准入预算。离线 `407 passed`；单帧预算失败保持，连续 3 帧 slow stop。

目标容器 1000 周期均为 `tracking`、14 FK/周期；姿态 `ratio=0.03189`、`scale=0.730`：

| 测量范围 | median | P95 | max |
| --- | --- | --- | --- |
| 独立 `DampedIK.step` | 7.368 ms | 8.894 ms | 14.829 ms |
| 完整 `_send_motion` 准入链 | 10.169 ms | 11.782 ms | 14.397 ms |

未出现 `hold_budget`、Safety Stop 或 100 ms 长尾。这是两组测量，不将独立 step 的最大值当作同一周期的子项。基准禁发目标及停止命令，满足当时 18/20 ms 预算；**不覆盖真实发送、XR 完整主循环、跟踪、方向、物理安全或后续版本的重新验收**。普通入口 Dry Run 的异常/退出停止行为另见操作页，不能套用基准脚本的边界。

逐轮数据见[原汇总 §2.10](archive/2026-10-25-documentation/originals/docs/决策与结论汇总.md#210-dls-周期超时性能归因2026-09-22十余轮实测)、[9 月 22 日原日志](archive/2026.9.22.md)、[9 月 23 日日志](logs/2026.9.23.md)。

## 4. 已废弃 / 被推翻的结论

### 4.1 架构与映射

| 不再采用的结论 | 当前解释 |
| --- | --- |
| SDK 是头显局部系，需乘头显世界位姿 | SDK 已是启动锚定世界系；头部相对化需 `T_head⁻¹ T_ctrl` |
| 仿真应切旧 SIDE_MOUNT、加侧装显示参数 | 用户要求竖立显示并保留映射；该实验已回退，不留死代码 |
| `invert_tcp_xy=True` 是默认；SIDE_MOUNT 仍有运行引用 | 默认 False，当前两端 `_HARDWARE`；不能从旧 build/lib 判断 |
| 9 月 18 日收紧值仍是当前幅度 | 中间值 `0.4/0.4/0.05/0.35` → 当日 `0.25/0.25/0.03/0.20` 均属历史；当前 `1.0/0.25/None/0.20` |

### 4.2 安全与奇异保护

| 不再采用的结论 | 更正 |
| --- | --- |
| URDF 雅可比可批准控制器 TCP 运动 | 使用现场 DH/工具帧与显式变换；结构 URDF 仅离线分析 |
| v1 预测后仍发原笛卡尔目标也算约束 | 必须实际下发受检关节目标 |
| 退出永远放行 / 硬区所有方向全停 | 方向判据 + 单侧结构守卫；退出/切向仍受其他约束，不保证任意方向可退 |
| 阻尼不影响手感 | 离线偏转 13.8°–20.2°；当前步长用最小范数解，阻尼只诊断 |
| 段首不动只能怪奇异保护 | 逐关节加速度截断曾扭转步长；已改公共比例 |
| 冻结目标就等于停住 | 必须请求软停并等待反馈静止，否则在途轨迹仍可能执行 |
| J3/J5 足以判断全部奇异 | 肩部反例：J2=−25°、J3=55°、J5=60°，ratio=0.00109，轴交点距 J1 仅 3.2 mm |
| 用单个位姿拟合工作帧补 FK/UDP 偏差 | 不允许掩盖模型错误；历史额外反变换造成约 1.1 m 偏差（安装姿态 `[0,-90,0]`） |
| d6 / 工具变换可取 SDK 默认 | 现场 RM65-BI d6=161.2 mm，标准默认144 mm；17.2 mm 解释位置差，finger 工具解释姿态差 |
| B 解锁 / 所有 Home 都经过 DLS | B 只回位；入口默认关闭路径预检，走关节插值直发 |
| 单周期命令额度也能限制实测滞后 | 两种预算分开，不能靠放大跟随余量解决执行问题 |

### 4.3 性能排查中的证否

| 假设 / 尝试 | 当时证据与处置 |
| --- | --- |
| 主要是反馈线程争用 | 停 UDP 后 103.7→92.0 ms，每次仍约1.2 ms，不解释主耗时 |
| 只降次数 / 只降单价足够 | 两个乘数都要降；裸 SDK 20/0.147≈136 次，历史最坏222次仍超预算 |
| `np.r_` 是主因 | 本机1.96 µs/次，整步最多省0.6 ms，量级不符 |
| 容器每步开销固定 | 比值2.04×→6.14×，不固定 |
| 循环 GC 是主因 | 关闭后0.0656→0.0615 ms，约6% |
| 板子整体慢10倍 / SDK 慢 | 主体是调用内 NumPy 小运算数；不能据此排除一切环境因素 |
| severity=1 必然是角度硬区 | J3=95.21°、J5=−62.97°仍因条件数进入风险区 |
| DLS 拒绝因为算不出步长 | `tracking scale=0.194` 已有非零步长 |
| ndarray 快路径更快 | `_finite_tuple` 运算数542→1316，回退 |
| forward 对外返回元组更划算 | 类型契约影响过大，保持内部元组 / 对外数组 |
| 运算数−79%就能推到23 ms | 实测仍35.6 ms，固定单价估算过于乐观 |

### 4.4 批量帧合成：停止的实验

## 5. 历史提案与执行约束
